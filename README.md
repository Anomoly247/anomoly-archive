# The Anomoly Archive

Digital art store for **AO (Anom Originals)**.
Live at **[anomarsty.lol](https://anomarsty.lol)**.

Twenty original pieces — neon backgrounds, emote packs and profile art —
sorted into four tiers: Novelty → Curiosity → Relic → Anomoly.
Pay once, keep the full-resolution file.

## What's in here

- `index.html` — the storefront
- `catalog.json` — product data (titles, prices, tiers, payment links)
- `thumbs/`, `previews/` — watermarked images for the gallery

Static site, no build step. Published with GitHub Pages.

## About AO

Neon identity art, digital collectibles, kids' stories and games,
made by Eliza Wood in Woodbridge, VA since 2019.
